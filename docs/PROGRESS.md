- **린터** — 기본 규칙 74건 중 결함 규칙(F·E9·B) 9건만 채택하고 전부 수정.
  나머지는 보류 사유를 설정 파일에 남겼다.
- **디자인 카탈로그** — `/vibe-design` 이 외부 스킬 의존을 끊고, 라이선스와 링크를 실측한
  디자인 시스템 목록을 자체 보유한다. 매번 디자인 언어를 새로 발명하지 않는다.
- **공개 이전** — `ZEST-im` org 로 옮기고 공개 유지. 구 경로는 리다이렉트.
- **컨텍스트 경제** — 세션 시작 비용 21,446 → 867 tok. 요약 우선 로드, 완료 태스크 월별
  아카이브, 스킬 문서를 행동 규칙과 참조 자료로 분리. 이어서 9개 프로젝트에 같은 루틴을
  적용해 재현을 확인했다. 지금 12개 프로젝트의 hot 66,296 tok / 아카이브 684,324 tok —
  아카이브의 값어치는 지운 것이 아니라 **안 읽는 것**에 있다.
- **운영 신뢰성** — 폴더 rename 이 남긴 잔재를 정리했다. 주기 실행 launchd 잡 하나가
  옛 경로를 보고 28회 연속 실패해 **토큰 수집이 4일간 죽어 있었고**, 구 설치명으로 남은
  잡 하나는 없는 파일을 KeepAlive 로 무한 재시작하며 로그를 104MB 까지 키우고 있었다.
  둘 다 보드가 정상으로 보였기 때문에 조용했다. 재발을 막는 rename 점검 목록을
  `/vibe-harness` 문서에 넣었다 — **주기 실행 잡은 마지막 exit status 를 봐야 한다.**
